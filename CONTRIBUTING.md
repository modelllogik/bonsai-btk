# Contributing

Thank you for taking the time. This project is a spare-time effort for the openBIM
community and for vocational training; reviews may take a few days.

## Reporting an observation

Please describe what you see, not what you think is wrong with a tool:

1. **What you did** – steps, ideally with a small IFC file.
2. **What you observed** – and what you expected instead.
3. **Versions** – Blender, Bonsai, IfcOpenShell, this add-on, operating system.
4. **Where it comes from** – if you found the place in the source code, link it.
5. **A proposal** – if you have one.

If the cause lies in Bonsai or IfcOpenShell, the report belongs upstream. We will help
to move it there and link it here.

## Pull requests

- Keep one concern per pull request.
- Use Bonsai's API and operators. **Do not replace Bonsai functions at runtime**
  unless there is no other way; then explain why in the pull request and link the
  upstream report.
- User interface texts are in English.
- Code is licensed GPL-3.0-or-later, documentation CC BY 4.0 (see `REUSE.toml`).
  By submitting a pull request you agree to license your contribution under these terms.
- Example data must be **neutral or openly licensed**: no real owners, addresses or
  logos; name the source and licence of geodata.
- Do not paste text from standards; refer to them by clause and content.
- Name the tool versions you tested with.

## Language

Issues, pull requests and the main documentation are in English.
The guide for trainers in `docs/de/` is in German; corrections there are welcome in German.
